# 实训3 基于AI共创的海瞳鱼鉴开发任务文档编写

## 一、实训目标

1. 掌握基于 PRD 与 UI/UX 设计文档向 AI 提出开发任务需求的方法，理解设计到开发的转化逻辑
2. 学会将海瞳鱼鉴拆解为六个里程碑（M1 需求设计 / M2 数据准备 / M3 模型训练 / M4 后端 / M5 前端 / M6 集成交付），明确各模块任务、技术要求与交付标准
3. 理解开发任务文档的标准结构（任务总览、里程碑计划、任务分解、关键决策、风险与应对、交付清单）
4. 能够通过 AI 生成符合产品需求与设计规范的开发任务文档，并进行迭代优化
5. 掌握任务编号体系、可量化交付标准与风险表的编写方法

## 二、实训内容

### 1. 背景知识

简要介绍与本次实训相关的技术背景：

- **开发任务文档**：基于产品需求（PRD V1.3：41 FR / 15 NFR / 60 BR / 55 AC）与界面设计（UI/UX D9 V1.1）拆解开发模块、定义任务内容、明确技术要求、规划开发排期、制定交付标准的核心文档，是开发人员开展开发、项目管理人员进行进度管控的直接依据。

- **前后端分离开发**：前端聚焦界面渲染与交互实现（React 18 + TypeScript + Vite + Tailwind + AntD 5 + Zustand + Axios），后端聚焦业务逻辑与 API 提供（Python 3.12+ / FastAPI / SQLite / PyTorch），通过接口进行数据交互。

- **里程碑拆解（M1~M6）**：依据 PRD 第 12 章，海瞳鱼鉴开发划分为六个里程碑，按顺序推进：

  | 里程碑 | 名称 | 核心交付物 |
  | --- | --- | --- |
  | M1 | 需求设计 | PRD、数据库设计、API 接口契约、UI/UX 设计文档、产品原型 |
  | M2 | 数据准备 | 数据集盘点与复测、预处理流水线、数据划分 |
  | M3 | 模型训练 | ResNet18 迁移学习模型、对照实验、优化复测、OOD 评估 |
  | M4 | 后端开发 | FastAPI 服务（38 端点）、识别链路、测试套件 |
  | M5 | 前端开发 | React 应用（13 页面）、接口对账、路由冒烟 |
  | M6 | 集成交付 | 集成联调、验收测试、性能压测、部署文档 |

- **任务编号体系**：采用 `M<里程碑>-<两位序号>` 格式，如 `M1-01`（PRD 框架与正文撰写）、`M4-05`（识别链路）。每个任务须配可量化的交付标准。

- **硬性验收指标**：测试集准确率 acc ≥ 85%（实测 0.9963）、宏观 F1 ≥ 0.82（实测 0.9678）、单图端到端时延 ≤ 3 秒（实测 p50 90.8 ms）。开发任务文档须将这些指标分解到 M3（模型训练）与 M4（后端识别链路）。

- **技术栈约定**：前端端口 5180 / 后端端口 8000 / API 前缀 `/api` / 环境变量前缀 `SEATONG_`；模型为 ResNet18 迁移学习，输入 224×224，23 类。
