## 一、产品信息速览

| 项 | 内容 |
| --- | --- |
| 产品名称 | 海瞳鱼鉴 |
| 产品定位 | 面向 23 类海洋鱼类的 CNN 细粒度图像分类 Web 应用 |
| 产品形态 | B/S 架构 Web 应用，PC 与移动端浏览器访问，无需安装客户端 |
| 核心链路 | 上传水下照片 → 图像预处理 → 模型推理 → 返回物种、置信度与物种介绍 |
| 目标用户 | 渔业调查与研究人员、水产养殖与流通从业者、公众与科普用户 |
| 硬性指标 | 23 类识别；总体准确率 ≥ 85%；平均 F1 ≥ 0.82 |
| 技术栈 | 前端 React + TailwindCSS / Ant Design；后端 FastAPI；深度学习 PyTorch + ResNet18；存储 sqlite3 |
| 数据来源 | Fish4Knowledge 23 类公开数据集（两万余张，8:1:1 分层划分） |
| 待定项 | 英文名与项目代号（影响代码包名、PPT 英文标题、仓库命名） |
