海洋鱼类图像分类系统 · 产品架构图

依据《海洋鱼类图像分类系统项目任务书 V1.0.0》绘制 · 23 类海洋鱼类细粒度图像分类 B/S Web 应用

层级说明
L1 用户层 —— 三类使用群体，统一经浏览器（PC / 移动端响应式）访问，无需安装客户端。
L2 应用功能层 —— 任务书 2.2 的六大功能模块，构成产品对外可见的完整功能面。
L3 智能能力层 —— 任务书 3.3 的算法四阶段，是准确率 ≥85%、平均 F1 ≥0.82 两项硬指标的达成路径。
L4 技术支撑层 —— 任务书 3.2 技术选型表，前后端分离，模型与业务服务同源 Python。
L5 数据资源层 —— 训练与运行期资产。其中 物种知识库 为任务书隐含依赖：2.2 结果展示要求提供物种形态特征与习性介绍，但任务书未将其列入交付物。
交付带 —— 任务书 5.1 / 5.2 的成果汇总。

制图说明：本图为产品架构视角，非部署拓扑图；模型中"用户管理"模块的认证方案（JWT / Session）在任务书中尚未定义，待 PRD 阶段确认后补充。
