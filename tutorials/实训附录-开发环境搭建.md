# 实训附录 海瞳鱼鉴开发环境搭建

## 一、实训目标

1. 掌握 Python 3.12 虚拟环境的创建与依赖隔离方法
2. 学会 Node.js 18+ 前端运行环境的安装与验证
3. 理解 CUDA 12.6 与 cuDNN 的安装要点，能安装 torch/torchvision 的 cu126 版本
4. 能够初始化海瞳鱼鉴后端数据库并启动前后端做连通性验证
5. 掌握 GPU 可用性的验证方法（`torch.cuda.is_available()`）

## 二、实训内容

### 1. 背景知识

海瞳鱼鉴采用前后端分离架构：

- **后端**：Python 3.12 + FastAPI + Uvicorn + SQLite，推理依赖 PyTorch（cu126），图像预处理使用 Pillow 与 OpenCV。
- **前端**：Node.js 18+ 构建，Vite 工程，承担游客额度本地拦截与识别交互。
- **训练侧**：独立的 `ml/` 目录，基于 PyTorch cu126，在 RTX 4060 8GB（CUDA 12.6）上完成 ResNet18 迁移学习。

环境搭建的核心难点是 CUDA 工具链与 PyTorch 版本匹配：CUDA 12.6 必须搭配 `torch 2.14.0+cu126` / `torchvision` 的 cu126 预编译包，否则退化为 CPU 推理（速度大幅下降）。

### 2. 推荐环境

| 组件 | 版本 / 配置 |
|------|-------------|
| 操作系统 | Windows 10 / 11（64 位） |
| Python | 3.12.x |
| Node.js | 18.x 及以上（npm 9+） |
| NVIDIA 驱动 | 支持 CUDA 12.6 |
| CUDA Toolkit | 12.6 |
| cuDNN | 与 CUDA 12.6 匹配 |
| PyTorch | 2.14.0+cu126 |
| GPU（训练） | RTX 4060 8GB（可选，无 GPU 时 CPU 降级） |

### 步骤 4：安装 CUDA 12.6 与 cuDNN

**操作命令：**

```powershell

```

> 安装要点：
> 1. 下载 CUDA Toolkit 12.6 安装器，自定义安装勾选 `CUDA` 与 `cuDNN`（或单独下载 cuDNN for CUDA 12.x）。
> 2. 将 cuDNN 的 `bin/include/lib` 复制到 `C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v12.6\`。
> 3. 确认环境变量 `CUDA_PATH` 指向 `C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v12.6`。

**验证方法：**

```powershell
nvcc --version
[Environment]::GetEnvironmentVariable("CUDA_PATH", "Machine")
# 预期输出: 含 release 12.6；路径为 ...\CUDA\v12.6
```

**成功标志：** `nvcc --version` 显示 12.6，`CUDA_PATH` 指向 v12.6，`nvidia-smi` 中 CUDA Version ≥ 12.6。

## 五、故障排除

### 问题 1：激活虚拟环境报"无法加载脚本，因为禁止运行脚本"

**解决方案：**

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
cd "E:\基于CNN的海洋鱼类图像分类系统-海瞳鱼鉴\01.code\seatong\backend"
.\.venv\Scripts\Activate.ps1
```

### 问题 2：torch 安装后 `cuda.is_available()` 为 False

**解决方案：**

```powershell
pip show torch | Select-String -Pattern "Version"
pip uninstall -y torch torchvision
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
nvidia-smi
```

### 问题 3：CUDA 12.6 安装后 `nvcc` 找不到

**解决方案：**

```powershell
$env:PATH += ";C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v12.6\bin"
nvcc --version
```

### 问题 4：`init_db.py` 报模块缺失或路径错误

**解决方案：**

```powershell
cd "E:\基于CNN的海洋鱼类图像分类系统-海瞳鱼鉴\01.code\seatong\backend"
.\.venv\Scripts\Activate.ps1
Test-Path "scripts/init_db.py"
# 预期输出: True；确认在 backend 目录且虚拟环境已激活
```

### 问题 5：前端 `npm install` 报网络或版本错误

**解决方案：**

```powershell
node --version
npm config set registry https://registry.npmjs.org/
npm install
```
