# 实训2 基于AI共创的海瞳鱼鉴UI/UX设计文档编写

## 一、实训目标

1. 掌握基于 PRD 文档向 AI 提出 UI/UX 设计需求的方法，理解 PRD 到 UI/UX 的转化逻辑
2. 学会定义海瞳鱼鉴的核心界面布局、交互逻辑、设计令牌与响应式断点规范
3. 理解 UI/UX 设计文档的标准结构（12 章 + 附录）与「可回溯」第一原则
4. 能够通过 AI 生成覆盖 13 个页面的 UI/UX 文档，并进行优化调整
5. 掌握单文件零依赖产品原型（HTML）的生成与验收方法

## 二、实训内容

### 1. 背景知识

简要介绍与本次实训相关的技术背景：

- **UI/UX 设计文档**：用于规范产品界面布局、交互逻辑、视觉样式、页面流程的核心文档，是前端开发、UI 设计的直接依据。海瞳鱼鉴 UI/UX 文档全文 12 章（第 0 ~ 11 章）+ 附录 A ~ G，定稿版本 V1.1，遵循「可回溯」第一原则——每个界面元素都能回溯到来源：令牌 → 第 3 章，组件 → 第 4 章，页面 → 第 5 章，需求 → 追溯条。

- **设计令牌（Design Token）**：承载设计决策的具名变量，如 `--primary`、`--radius-lg`，是文档第 3 章的原子单位。令牌以 `tokens.css` 形式落地，前端通过 CSS 变量统一引用，避免样式散落。

- **三档断点**：PRD 决策基线定义的 768 / 1024 / 1440，分别对应移动端 / 平板 / 桌面三档响应式适配。所有页面需在窄屏（<768）、中屏（768~1024）、宽屏（>1024）三种宽度下保持可用。

- **组件化设计**：将界面拆分为可复用的按钮、表格、卡片、条形图等组件（文档第 4 章定义 26 个组件），保证界面一致性与开发效率。

- **目标技术栈**：React 18 + TypeScript + Vite + TailwindCSS / Ant Design 5。UI/UX 文档只回答「长什么样、怎么交互、用什么令牌与组件」，功能行为的权威定义仍在 PRD 第 4 章。

- **13 个页面清单**（PRD 第 5.2 节口径）：首页、识别工作台、历史记录列表、历史详情、历史对比、登录、注册、个人中心、管理（用户 / 记录 / 配置）、关于、404 兜底页，共 13 个页面，无一遗漏。


## 五、故障排除

### 问题1：AI 生成的 UI/UX 文档缺少可落地的 tokens.css

**现象：** 文档只用文字描述颜色（如「主色为蓝色」），未给出具名令牌与 CSS 变量，前端无法直接引用。

**解决方案：**

明确要求 AI 输出 `:root` 下的令牌声明片段，并以 `--primary` / `--danger` 等具名变量表达；随后用 PowerShell 核对令牌是否落地：

```powershell
Get-Content "E:\基于CNN的海洋鱼类图像分类系统-海瞳鱼鉴\04.实训指导书\AI共创过程文档\海瞳鱼鉴_UIUX设计文档_练习.md" | Select-String ":root|--primary|--danger"
# 若无命中，返回 AI 要求补充 tokens.css 片段
```

### 问题2：13 个页面出现遗漏或多余

**现象：** AI 漏写「历史对比」或「管理-配置」等页面，或擅自增加 PRD 未定义的页面。

**解决方案：**

用脚本遍历 13 个标准页面名称，定位缺失项，再要求 AI 补齐或删除多余页面：

```powershell
$pages = @("首页","识别工作台","历史记录列表","历史详情","历史对比","登录","注册","个人中心","管理-用户","管理-记录","管理-配置","关于","404")
$content = Get-Content "E:\基于CNN的海洋鱼类图像分类系统-海瞳鱼鉴\04.实训指导书\AI共创过程文档\海瞳鱼鉴_UIUX设计文档_练习.md" -Raw
foreach ($p in $pages) { if (-not $content.Contains($p)) { "缺失页面: $p" } }
# 输出所有未命中的页面名称，返回 AI 补齐
```

### 问题3：原型无法离线打开或依赖构建工具

**现象：** 生成的 HTML 引用了本地 npm 包或需要 `npm run dev` 才能预览，不符合单文件零依赖要求。

**解决方案：**

要求 AI 改用 Tailwind CDN（或纯手写 CSS）、内联所有样式与脚本，移除任何 `import` 外部模块；核对是否含有外部依赖声明：

```powershell
Get-Content "E:\基于CNN的海洋鱼类图像分类系统-海瞳鱼鉴\04.实训指导书\AI共创过程文档\海瞳鱼鉴_产品原型_练习.html" | Select-String "require\(|import .* from|node_modules"
# 预期输出: 若无命中则说明无构建依赖；若有命中需返回 AI 改写为内联
```

### 问题4：断点取值与 PRD 决策基线不符

**现象：** AI 自行使用 375/768/1280 等其他断点，偏离 PRD 的 768/1024/1440 口径。

**解决方案：**

在 Prompt 中显式锁定三档断点，并用 PowerShell 核对原型与文档中的断点数值：

```powershell
Get-Content "E:\基于CNN的海洋鱼类图像分类系统-海瞳鱼鉴\04.实训指导书\AI共创过程文档\海瞳鱼鉴_UIUX设计文档_练习.md" | Select-String "768|1024|1440"
# 预期输出: 三档数值均被命中且不含其他冲突断点
```
