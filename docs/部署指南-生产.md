# 海瞳鱼鉴（Seatong）生产部署文档

## 一、部署形态

**项目名称**：基于CNN的海洋鱼类图像分类系统（海瞳鱼鉴 / SeaPupil）

生产环境采用 **Nginx 反向代理 + HTTPS** 部署：

- **前端**：本包 `frontend-dist/` 为已构建的生产静态资源（`npm run build` 产物），由 Nginx 托管
- **后端**：本包 `backend/` 以 uvicorn 运行（端口 8000），Nginx 将 `/api` 反向代理至后端
- **数据库**：SQLite 单文件（`backend/seatong.db`，首次部署由 `scripts/init_db.py` 初始化）

| 组件 | 端口 | 说明 |
| --- | --- | --- |
| Nginx | 443（HTTPS）/ 80（跳转） | 对外入口，托管前端静态资源 |
| 后端 uvicorn | 8000（仅内网） | API 前缀 `/api` |
| SQLite | - | 本地文件存储，7 表 64 字段 |

## 三、部署步骤

### 步骤 1：部署后端

```powershell
cd <交付包>\部署版code\seatong\backend
pip install -r requirements.txt   # 若无 requirements 文件，按 README_dev 依赖清单安装
python scripts\init_db.py
python scripts\seed_data.py
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

**验证方法：**

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/api/health" -Method GET
# 预期输出: 返回健康检查 JSON
```

> 生产环境后端仅监听 127.0.0.1，由 Nginx 对外暴露；请勿将 8000 端口直接开放公网。

### 步骤 2：部署前端静态资源

将本包 `frontend-dist/` 全部内容复制至 Nginx 站点目录，例如：

```powershell
Copy-Item -Recurse "<交付包>\部署版code\seatong\frontend-dist\*" "C:\nginx\html\seatong\"
```

**验证方法：**

```powershell
Test-Path "C:\nginx\html\seatong\index.html"
# 预期输出: True
```

### 步骤 3：生成 HTTPS 证书（自签）

```powershell
openssl req -x509 -nodes -days 365 -newkey rsa:2048 `
  -keyout "C:\nginx\conf\seatong.key" `
  -out "C:\nginx\conf\seatong.crt" `
  -subj "/CN=seatong.local"
```

### 步骤 4：配置 Nginx

参考本包 `deploy/nginx.conf`，核心要点：

1. 443 端口监听 SSL，证书指向步骤 3 生成的文件
2. `location /` 指向前端静态目录，并配置 `try_files ... /index.html`（SPA 路由回退）
3. `location /api/` 反向代理至 `http://127.0.0.1:8000`，并放大 `client_max_body_size`（单图 ≤10 MB、批量 ≤9 张，建议设为 100m）
4. HTTP 80 端口 301 跳转 HTTPS

```powershell
C:\nginx\nginx.exe -t        # 校验配置
C:\nginx\nginx.exe           # 启动
C:\nginx\nginx.exe -s reload # 重载
```

### 步骤 5：整体验收

- 浏览器访问 `https://<域名或IP>/`，预期加载海瞳鱼鉴首页（锁形图标，无混合内容告警）
- 上传一张鱼类图片执行识别，预期返回 Top-1 物种 + 置信度 + Top-5 候选
- 注册/登录、历史记录、CSV 导出、后台管理逐项验证

## 四、生产安全要点

1. **后端不直连公网**：仅 Nginx 对外，后端绑定 127.0.0.1
2. **HTTPS 强制**：HTTP 全部 301 跳转 HTTPS；生产请使用受信任 CA 证书（自签证书仅适用于内网/教学）
3. **限流保护**：后端内置 60 次/分钟限流（错误码 42902），Nginx 可再叠加 `limit_req`
4. **数据备份**：定期备份 `seatong.db` 与 `backend/storage/images/`
5. **环境变量**：模型路径等敏感配置通过 `SEATONG_` 前缀环境变量注入，勿写入代码

***

## 五、常见问题

### 问题 1：Nginx 502 Bad Gateway

**现象：** 访问 /api 返回 502。
**解决方案：** 确认后端 uvicorn 已启动且监听 127.0.0.1:8000；检查 `proxy_pass` 末尾斜杠与 `/api/` 匹配关系。

### 问题 2：上传大图失败（413）

**现象：** Nginx 返回 413 Request Entity Too Large。
**解决方案：** 在 `http` 或 `server` 块中设置 `client_max_body_size 100m;` 后 reload。

### 问题 3：前端刷新 404

**现象：** 二级路由刷新返回 404。
**解决方案：** 确认 `location /` 中配置了 `try_files $uri $uri/ /index.html;`。

### 问题 4：模型加载失败（503）

**现象：** 识别接口 503xx 错误。
**解决方案：** 检查 `ml/models/M1_ood_tuned/best.pt` 相对路径或 `SEATONG_MODEL_PATH` 环境变量；回滚可指回 `M1_main_224/best.pt`。
